# Student Mathematics Performance Analytics

## 📌 Project Overview
Identifying the factors that lead to poor academic performance is challenging due to the complex mix of demographic, social, and study-related variables. This project analyzes student records to measure the impact of study habits, absences, and past grades on final academic outcomes, establishing a data-driven foundation for early educational intervention.
